AnyPS5 — Port executables to Linux and Windows without an emulator.

A toolchain for porting executables to another operating system: a relinker converts a binary into the target's native format and a set of system PRX libraries provides dynamic-link implementations, with no emulation or separate runtime.

View on GitHub Quick start 
cmake -B build

An emulator is a second operating system to maintain.

The relinker produces a native executable and native libraries.

A port needs the interfaces the binary expects.

The PRX library set supplies them at link time.

The work is hard to repeat.

The build and the relink steps are documented and scripted.
